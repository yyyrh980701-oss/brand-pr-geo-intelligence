# Brand PR GEO Intelligence · 清洁分享版

品牌 PR 的 GEO/SEO、AI 可见度、舆情巡检、KOL 推荐、竞品分析一体化 skill。
基于 E-E-A-T + V 五维评估框架，多租户数据物理隔离，追加式落盘 + 证据硬卡。

## 核心用法

**直接贴一个官网 URL**，skill 会先问你 10 道题，答完才开始采集。

回答方式：`1A 2C 3B 4AF 5B 6D 7C 8A 9B 10D`，不确定的写「不确定」，会给你推荐。

这 10 道题决定采什么、采多深、报告给谁——业务口径、内容产能、表达红线、报告受众，
这些爬取拿不到，只有你知道。**跳过它就会先爬一堆再回头对齐，方向是反的。**

## 工作模式

| 模式 | 适合场景 | 交付形式 | 核心功能 |
|---|---|---|---|
| 快速诊断 | 一次性摸清现状和最大问题 | 白话化带图 PDF（HTML 可选） | E-E-A-T + V 雷达图、四引擎 AI 可见度快照、体检结论与红黄灯 |
| 完整策略 | 从诊断走到具体执行方案 | 白话化带图 PDF + Markdown 策略包（HTML 可选） | 快速诊断全部内容、完整 GEO/SEO 策略、竞品横纵分析、KOL 分层名单 |
| 持续监测 | 持续盯盘，周期性汇报 | 动态仪表盘 + 周期 PDF | 完整策略全部内容、舆情告警、每日社媒动态和周期报告 |

详细流程边界见 `references/work-modes.md`。所有模式均可使用；未指定时默认快速诊断。

## 安装

```bash
cp -R geo-skill-dist ~/.claude/skills/brand-pr-geo-intelligence
```

## 使用前请自行填写

| 项 | 说明 |
|---|---|
| `configs/tenants.yaml` | 你的租户清单（分享版为空模板）。也可以直接贴 URL，走 10 道题现场建档 |
| `configs/kol_radar_dict.yaml` | 你的行业 KOL 候选池（分享版为空模板） |
| `TIKHUB_API_KEY` | 社媒检索（X / Reddit / 微博 / 小红书 / 知乎）。缺失则降级 Playwright |
| `TAVILY_API_KEY` | 通用搜索降级方案，可选，多数场景 WebSearch 够用 |
| 投递渠道 | 邮箱 / Slack 等，写在 tenants.yaml 对应字段 |

**凭证一律走环境变量或 `~/geo-agent-data/.env`，不要提交进仓库。**
详细步骤与自检命令见 `references/setup.md`。

## 关于定时任务

**本版本不含任何预置定时任务。** 是否建立取决于 10 道题里 Q7（巡检周期）和 Q8（投递渠道）
的答案；Q7 选「一次性诊断」就不建。创建前会先跟你确认执行时间、时区、投递渠道和失败告警方式。

## 这个版本不包含什么

- ❌ 任何具体公司 / 客户数据、竞品情报与实战笔记
- ❌ 任何预置定时任务
- ❌ 任何 API Key、Cookie、邮箱、Slack 频道 ID

## 依赖的其他 skill（可选）

- `hv-analysis` — 横纵分析深度研究，模块8 调用；未安装时模块8 降级为普通竞品对比
- `neat-freak` — 会话收尾时的文档与记忆同步
