# E-E-A-T + V 五维评估框架

> 基于 Google Search Quality Rater Guidelines，扩展 V（AI Visibility）维度。

## 五维定义与评分细则

### E₁ Experience 经验（20 分）
品牌是否有第一手行业实践证据？

| 分段 | 判据 |
|---|---|
| 16–20 | 官网/内容中有可核验的一手数据（自有交易量、客户案例、实测数据、现场影像） |
| 11–15 | 有案例但缺量化或缺第三方印证 |
| 6–10 | 仅有宣称式表述（"多年经验""服务众多客户"）无证据 |
| 0–5 | 无任何实践证据，或证据与公开事实矛盾 |

### E₂ Expertise 专业度（20 分）
团队是否具备公认的专业能力？

| 分段 | 判据 |
|---|---|
| 16–20 | 核心团队实名 + 可核验履历（LinkedIn/公开任职/论文/专利），内容有署名作者 |
| 11–15 | 部分团队披露，内容署名不全 |
| 6–10 | 仅有公司层面表述，团队匿名 |
| 0–5 | 团队完全匿名 + 内容无署名（⚠️ 高风险信号） |

### A Authoritativeness 权威度（20 分）
外部权威信源如何评价品牌？

| 分段 | 判据 |
|---|---|
| 16–20 | 主流媒体报道 / 行业榜单 / 监管备案 / 高质量外链多源覆盖 |
| 11–15 | 有行业媒体或垂直媒体报道，权威层级偏低 |
| 6–10 | 仅有自媒体、PR 稿、付费收录 |
| 0–5 | 无任何第三方提及 |

### T Trustworthiness 信任度（20 分）
信息是否准确、透明、可验证？

| 分段 | 判据 |
|---|---|
| 16–20 | 主体资质/注册信息/联系方式/隐私政策齐全，声明可逐条核验，有第三方评价（Trustpilot 等） |
| 11–15 | 基本信息齐全但缺第三方评价 |
| 6–10 | 关键信息缺失（无主体、无地址、域名新注册） |
| 0–5 | 存在不实声明（如"20 年经验"但域名注册 1 年） |

### V Visibility AI 可见度（20 分）
AI 搜索引擎在关键 query 中是否推荐？

- 取 **5–10 条核心 query**（品类词 + 场景词 + 竞品对比词），跑四引擎快照。
- 单 query 计分：**被点名推荐 2 分 / 被提及未推荐 1 分 / 未出现 0 分**，归一化到 20 分。
- 四引擎：AI Overviews、Perplexity、ChatGPT Search、Gemini（不可用的引擎标注为「本期缺采」，从分母剔除并注明）。

## 总分与等级

| 等级 | 分数 | 含义 |
|---|---|---|
| **A** | 85+ | 可见度资产已成型，转入维护与扩张 |
| **B** | 70–84 | 基础扎实，V 或 A 维度有明确短板 |
| **C** | 50–69 | 存在结构性缺口，需专项补齐 |
| **D** | <50 | 基础信任要件缺失，先补 T/E₂ 再谈 GEO |

## 输出要求

1. **五维雷达图**（ECharts），支持竞品叠加与多期叠加（月初 vs 月末），追踪 V 分动态。
2. 每个维度必须给出：得分 + 判据引用（URL/截图路径）+ 一条可执行动作。
3. **不得给出无证据的分数**。取不到证据的维度记 `null` 并标注「本期缺采」，不要给 0 分充数——0 分是判断，缺采是事实，两者不可混同。
4. 分数落盘至 `ledger/eeatv_scores.csv`。
