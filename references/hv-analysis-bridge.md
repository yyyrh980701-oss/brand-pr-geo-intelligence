# 模块8：竞品横纵分析（调用 hv-analysis）

**触发**：横纵分析 / 竞品研究 / 深度研究
**建议前置**：模块2（关键词矩阵界定研究边界）

## 执行

调用 `hv-analysis` skill，传入：

- 研究对象（本租户 + 3–5 家竞品）
- 纵轴时间范围（一般 5–10 年，或竞品成立至今）
- 横轴对比维度（从模块1 画像字段 + 模块2 关键词矩阵推导）
- 目标：找出**我方可占的叙事位**

## 回填

`hv-analysis` 产出 PDF 研究报告后，把结论回填进 GEO 工作流：

1. **关键洞察 ≤500 字**（Token 洪流控制）写入 `daily/YYYY-MM-DD_hv-analysis.md`
2. 竞品 EEAT-V 评分 → `ledger/eeatv_scores.csv`（用于雷达图叠加）
3. 发现的内容缺口 → 回流模块2 的内容规划
4. 发现的竞品攻击面/风险 → 回流模块4 监控清单

## 红线

- 竞品负面信息必须有可核验来源，且在对外内容中**只用客观事实**，不用贬损性表述。
- 竞品数据（营收、规模）标注来源与统计期；推测值明确标为推测。
