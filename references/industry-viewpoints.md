# 模块6：行业观点与叙事补给

**触发**：最近行业有什么 / 周报 / 月报 / 趋势

## 目标

给 PR/内容团队**可直接用的弹药**：行业正在讨论什么、我方该用什么口径接。

## 采集

1. 行业媒体近 7/30 天头条（WebSearch + WebFetch）
2. 监管/政策动态（关键市场逐个查）
3. 竞品与同行的公开表态
4. 数据机构报告（行业协会、权威研究机构等）
5. 结合 `Watch List`（见 `configs/tenants.yaml` 的 `watch_list`）

## 输出格式

每条观点 **≤200 字**（Token 洪流控制）：

```
### {观点标题}
* 事实：{发生了什么，附来源链接}
* 影响：{对本租户意味着什么}
* 我方口径：{一句话可对外表述}
* 可产出内容：{标题 + 形态}
```

周报 5–8 条，月报 10–15 条 + 一段趋势总结。

## 落盘

`daily/YYYY-MM-DD_viewpoints.md`，并追加进 `monthly/YYYY-MM_master.md`。

## 红线

- 每条事实必须有链接。**无来源的"业内普遍认为"一律删除**。
- 政策/法规类信息标注生效日期与适用地域，不确定的写「需法务确认」。
