# 模块7：活动策划 & GEO 联动

**触发**：发布会 / 沙龙 / 直播 / 活动 / 峰会
**可选前置**：模块2（有关键词矩阵则活动内容可直接对齐目标词）、模块3（嘉宾/KOL 名单）

## 核心思路

活动不是终点，是**内容资产的生产事件**。策划时就要设计好：这场活动之后，会留下哪些可被 AI 引用的页面。

## 策划要素

1. **主题与叙事**：一句话主张 + 三个支撑点，对齐 L1/L2 关键词
2. **形式与规模**：线上/线下、时长、人数、预算档位
3. **嘉宾矩阵**：主讲/对谈/媒体（KOL 走模块3 验证流程）
4. **内容日历**：预热（T-14 ~ T-1）→ 当日 → 长尾（T+1 ~ T+30）
5. **GEO 联动设计**（关键）：
   - 活动落地页（含结构化信息：时间/地点/议程/嘉宾，AI 易抓取）
   - 会后**成果页**：数据、观点摘要、可引用结论 —— 这是真正吃 GEO 流量的页面
   - 媒体通稿投放清单（优先 AI 引擎已在引用的信源）
   - 可复用素材：图表、金句、影像
6. **KPI**：曝光 / 报名转化 / 媒体覆盖 / **会后 30 天目标词 AI 可见度变化**

## 输出

用 `templates/event-plan-output.md`。落盘 `daily/YYYY-MM-DD_event-plan.md`。

## 红线

- 预算/报价类数字须标注「待供应商确认」。
- 嘉宾未确认前一律写「拟邀」，不得写成已确认。
