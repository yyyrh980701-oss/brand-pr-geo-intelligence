# 工作模式与流程深度

工作模式只决定本次任务做到多深，不是价格、套餐或权限门槛。任何用户都可以明确选择完整流程；未指定时从快速诊断开始，以免一次产出过重。

## 模式总览

| 模式 | 适合场景 | 交付形式 | 核心边界 |
|---|---|---|---|
| 快速诊断 | 一次性摸清现状和最大问题 | 白话化带图 PDF（HTML 可选） | 只做体检，最多给 3 条优先动作，不建监测任务 |
| 完整策略 | 从诊断走到具体执行方案 | 白话化带图 PDF + Markdown 策略包（HTML 可选） | 提供关键词、内容、竞品、KOL 和路线图，不做持续盯盘 |
| 持续监测 | 长期跟踪并周期汇报 | 动态仪表盘 + 周期 PDF | 连续监测、告警与周期报告；定时和外发仍需确认 |

## 执行规则

### 快速诊断

- 输出可离线打开的白话化带图 PDF；用户明确需要时可附 HTML 仪表盘。
- 包含 E-E-A-T + V 评分、AI 可见度快照、核心问题诊断和红黄灯优先级。
- 专业术语首次出现时给人话解释，英文检索问题同时保留中文释义。
- 最多给 3 条最高优先级动作，不展开完整关键词矩阵、90 天路线图、KOL 名单或竞品深度分析。
- 不创建定时任务，不外发告警，不承诺周期更新。

### 完整策略

- 包含快速诊断全部内容。
- 增加关键词矩阵、内容规划、90 天路线图和 GEO/SEO 优先级。
- 增加竞品横纵分析、KOL/分析师分层名单和触达建议。
- 邮件、DM、Slack、发帖等外发动作仍需用户单独确认。
- 不做持续监测；若用户要求盯盘，切换到持续监测模式。

### 持续监测

- 包含完整策略全部内容。
- 启用动态仪表盘、舆情巡检、告警投递、每日社媒/竞品动态和周期 PDF。
- 创建定时任务前必须确认执行时间、时区、投递渠道和失败告警方式。
- 监测失败必须写入“当日缺失”占位，不能用推测数据填补时间序列。

## 模式切换口径

- 用户说“先看看现状”“做个体检” → 快速诊断。
- 用户说“完整流程”“给我落地方案”“从诊断做到执行” → 完整策略。
- 用户说“持续盯盘”“自动告警”“每天/每周跟踪” → 持续监测，并补齐定时与渠道确认。
- 不使用报价、套餐、付费升级或权限解锁语言；模式之间可以按用户需要直接切换。
