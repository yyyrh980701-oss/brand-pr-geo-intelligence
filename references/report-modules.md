# 模块2：GEO/SEO 策略生成

**触发**：SEO / GEO / AI 搜索 / 关键词 / 排名 / 内容策略 / 可见度
**前置**：模块1 画像已确认（未确认先补）。

## 一、关键词矩阵

四层结构，每层 5–15 个词，全部标注**搜索意图**与**竞争度依据**：

| 层 | 类型 | 示例形态 | 作用 |
|---|---|---|---|
| L1 | 品类词 | "{品类词，如 xxx supplier}" | 抢品类认知 |
| L2 | 场景/问题词 | "how to {用户真实操作意图}" | 承接真实需求 |
| L3 | 竞品对比词 | "{brand} vs {competitor}" | 拦截比较流量 |
| L4 | 品牌词 | "{brand} review / legit?" | 守住品牌搜索 |

每个词给出：月搜索量级（有数据源写来源，无则标注「量级估计·需验证」）、当前排名、AI 引擎是否引用、建议内容形态。

## 二、AI 问答快照（GEO 核心）

对 L1–L3 各挑 2–3 个词，在四引擎实测：

- 记录：**是否出现品牌 / 出现位置 / 被引用的信源 URL / 竞品是否被推荐**。
- 关键产出是**「AI 引用了谁」**——被引用的信源就是要拿下的阵地（行业媒体、Reddit 帖、榜单站、维基类）。
- 原始截图/文本落 `snapshots/`，结论落 `daily/`。

## 三、内容规划

按「先补信任、再抢可见度」排序：

1. **T/E₂ 补齐类**（如团队页、资质页、方法论页）——GEO 的地基，缺了后面白做。
2. **AI 可引用类**：结构化、有数据、有明确结论的页面（对比表、定义页、FAQ、行业数据页）。
3. **长尾承接类**：L2 场景词的问答内容。
4. **对比拦截类**：L3 竞品对比页（客观、可核验，避免贬损性表述）。

每条给出：标题 / 目标词 / 内容形态 / 需要的一手素材 / 预计难度 / 负责方。

## 四、输出

- 大纲用 `templates/geo-seo-report-outline.md`。
- 完成画像、评分与结论确认后，按 `references/pdf-delivery.md` 生成白话化带图 PDF，并逐页验收。
- HTML 仪表盘为可选补充：`scripts/gen_html_report.py` + `templates/geo-visibility-dashboard.html`。
- 落盘：关键词矩阵 + AI 快照 → `daily/`；EEAT-V 分 → `ledger/eeatv_scores.csv`。

## 红线

- 搜索量、排名数据**没有数据源就标注估计**，不得伪装成实测。
- 不给「堆关键词」「批量 AI 生成 100 篇」这类会反噬的建议。
- 每条建议都要能回答「凭什么这条能提升 AI 可见度」。
