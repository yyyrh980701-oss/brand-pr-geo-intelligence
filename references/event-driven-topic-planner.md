# 模块10：事件驱动选题

**触发**：热点 / 这个新闻 / 这个事件 / 能写什么 / 借势

## 三步法

### 1. 事件核实（不可跳过）
- 抓原始信源（不是二手转述），落 `snapshots/`
- 确认：发生时间、事实边界、争议点、官方口径
- **信源不可靠 → 直接建议不碰**。借势借错，损失远大于收益。

### 2. 相关度判定

| 判据 | 说明 |
|---|---|
| 品类相关 | 事件是否发生在本租户所处品类/产业链 |
| 客群相关 | 目标客群是否在关心这件事 |
| 立场安全 | 我方是否有可站得住的立场（不涉政治、不踩监管、不消费灾难） |
| 时效窗口 | 还剩多久（≤48h 走快评，>3 天可做深度） |

四项有一项不过 → 不建议借势，说明原因。

### 3. 选题产出（3–5 个）

```
### 选题{N}：{标题}
* 角度：{我方从什么位置说话}
* 一句话主张：
* 支撑素材：{一手数据/案例，缺则标注需补}
* 形态：{快评/深度/图文/视频}
* 目标词：{对齐模块2 关键词矩阵}
* 时效：{今日发/本周发}
* 风险提示：{可能的反噬点}
```

## 红线

- **不碰**：政治敏感、灾难消费、竞品负面事件的踩踏式借势、监管争议中的站边。
- 事件事实必须附链接；未核实的写「待核实」，不进入选题。
